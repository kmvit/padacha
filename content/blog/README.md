# Исходники статей блога

Статьи живут в базе сайта и правятся в админке (раздел «Статьи»). Файлы
`<адрес>.md` здесь — формат для партий: написать заранее, закоммитить и
залить командой

```bash
.venv/bin/python manage.py import_articles                     # новые статьи
.venv/bin/python manage.py import_articles menyu-dlya-kofejni  # только эту
.venv/bin/python manage.py import_articles --force menyu-dlya-kofejni  # перезаписать правки из админки
```

Уже залитые статьи повторный импорт не трогает: после заливки главная
версия — в админке.

## Публикация по расписанию

У каждой статьи — время выхода по Москве: `published: 2026-10-25 09:00`.
Оно становится полем «Выход»: пока время не наступило, статьи нет ни на
сайте, ни в списке, ни в sitemap. Вошедший в админку видит её по прямой
ссылке — это и есть предпросмотр.

Когда время наступает, статья появляется сама, без пересборки. Таймер
`padacha-indexnow.timer` раз в 15 минут сообщает поисковикам о вышедших
статьях через IndexNow. Ритм — две статьи в день, слоты 09:00 и 15:00.

Отправить адреса в IndexNow руками (например, после правки страницы):

```bash
.venv/bin/python manage.py indexnow /blog/menyu-dlya-kofejni/ /sklad/
```

```
---
Первый абзац статьи (без заголовка).

## Подзаголовок

Обычный Markdown: **жирный**, списки, таблицы, [ссылка](/sklad/).

> [Формула]
> Фудкост, % = себестоимость ÷ цена × 100

=== faq

### Вопрос, как его задают в поиске?
Ответ. Абзацы — через пустую строку.

### Второй вопрос?
Ответ.

=== related

- /blog/fudkost/ | Фудкост | Подпись под ссылкой
- /qr-menu/ | QR-меню | Подпись
```

Правила:

- `title` — до 60 знаков, с главным запросом в начале. `description` — до 160.
- `h1` не повторяет `title` дословно; перенос строки — `<br>`.
- Цитата `>` становится оранжевой врезкой. Первая строка в квадратных
  скобках — метка врезки (`[Формула]`, `[Пример]`, `[Падача считает это сама]`).
- Колонки таблицы, где только числа, выравниваются вправо сами.
- Заголовки `#` в тексте превращаются в `##`: h1 на странице один.
- В `=== faq` — вопросы для блока и для FAQPage в микроразметке.
- В `=== related` — три ссылки «Рядом по теме»: адрес | название | подпись.
